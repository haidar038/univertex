# Panduan Panitia (Committee) — UniVertex

## Login
1. Buka `/login` dengan akun panitia (dibuat via undangan admin).
2. Anda masuk ke `/committee`.

## Tugas
- Buka election yang ditugaskan → pantau tally (`/committee/election/:id`).
- Tambah observasi/catatan bila ada kejadian (tersimpan append-only).
- TIDAK dapat mengubah kandidat, suara, atau jadwal.

## Koordinasi
- Laporkan anomali ke admin via channel helpdesk.
- Prosedur sengketa: `docs/SOP-Helpdesk-HariH.md`.
