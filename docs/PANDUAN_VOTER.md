# Panduan Pemilih (Voter) — UniVertex

## Cara Login
1. Buka `/login`.
2. Masukkan email & password (diberikan saat akun dibuat via undangan).
3. Klik "Masuk".

## Cara Vote
1. Setelah login, Anda masuk ke dashboard (`/app/dashboard`).
2. Lihat daftar pemilihan yang tersedia (hanya yang DPT Anda).
3. Klik "Mulai Voting".
4. Pilih SATU kandidat/pasangan.
5. Klik "Konfirmasi Pilihan" → "Ya, Saya Yakin" (tidak bisa dibatalkan!).
6. Tunggu notifikasi "Suara Anda berhasil tercatat".
7. Logout jika sudah selesai (terutama di device bersama).

## Kendala
- "Tidak termasuk DPT" → hubungi admin/panitia, jangan coba vote ulang paksa.
- "Sudah memberikan suara" → 1 voter = 1 suara, tidak bisa diubah.
- Lupa password → klik "Lupa password" di halaman login, cek inbox.

## Bantuan
Hubungi helpdesk panitia (lihat info di halaman pemilihan).
